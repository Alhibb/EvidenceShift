An initial EvidenceShift pilot produced perfect decision accuracy with and without explicit evidence checks. We therefore constructed a separate counterfactual follow-up rather than changing those completed results. The new test contains 24 fictional cases in 12 pairs. Within each pair, one document changes and the correct answer changes. Cases address operative dates, amendment scope, delegated authority, version history, unresolved conflicts and missing information. Using Gemini 3.8 Flash, we compare a concise baseline, a generic instruction and targeted evidence checks. The latter two instructions each contain 77 words. Two document orders yield 144 test responses. Pair accuracy, requiring both variants to be correct, was 79.2% for baseline, 83.3% for the generic control and 75.0% for evidence checks. The primary paired difference was -8.3 percentage points, with an exploratory bootstrap interval of [-20.8, 0.0]. The targeted instruction scored -8.3 percentage points relative to the generic control on pair accuracy. Post-hoc inspection found all 25 scored failures questioned packet applicability to the named organisation, exposing an implicit task convention. Independent author review of all 24 test packets agreed with 33.3% of gold labels, confirming substantial ambiguity when packets lack explicit organizational linkage. The study provides reproducible evidence about this evaluation setup, not a claim of real-world reliability or universal prompt equivalence.
