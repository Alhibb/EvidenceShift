# Sprint completion checklist

Source checked 14 November 2026: https://apartresearch.com/sprints/ai-x-epistemics-research-sprint-2026-11-13-to-2026-11-15

Submission cutoff: 15 November 2026, 23:59 AoE = 16 November 2026, 11:59 UTC = **Monday 16 November 2026, 12:59 p.m. WAT (Nigeria)**. Recheck the official page before submission for any changes.

- Sign up on the event page and obtain access to the official community. This package does not register you.
- Confirm model access and cost limits; check parameters on the development set.
- Review all 48 dataset cases, record real review identities and corrections, freeze the final files.
- Run the prespecified experiment; preserve raw outputs and failures.
- Review output evidence with the blinded rubric and report reviewer counts honestly.
- Complete the report using the **official template linked under Guidelines → Submission Requirements** on the event page. The Markdown scaffold here is planning material, not a replacement for that template.
- Keep the main report to eight pages maximum, excluding references and appendices.
- Supply a 150–250-word abstract, project title, author names and affiliations.
- Include the required Limitations and Dual-Use / Ethical Considerations appendix.
- Clearly separate prior work and new sprint work; disclose AI assistance accurately.
- Verify every number, reference and claimed experiment. Negative or unfinished findings must be labelled honestly.
- Optionally provide a public repository and a 3–5-minute video. A polished UI is not a substitute for measured results.
- Upload the final PDF via the official submission form. Check the confirmation email. Nothing has been submitted automatically.

Suggested working order: model connectivity and development run; dataset review and final freeze; 160-call test run; analysis and blinded review; report and final PDF inspection. Prioritise the empirical record over extra interface work.
